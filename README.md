# grocery-store

Generated by `create-universal-app` (blog-cms, React variant). A WordPress-style blog:
public Markdown blog + admin dashboard, backed by a Node.js (Express) API.

## Develop

```bash
pnpm install
pnpm dev        # Express API on :4000, React client on :5173 (proxies /api)
```

Open http://localhost:5173 — the public blog. Admin lives at **/admin**.

> **Security:** the default `admin` password and generated session key are for local
> development only. Production startup refuses to run unless both `ADMIN_PASSWORD` and
> `SESSION_SECRET` are set. Keep them out of source control and serve the admin over HTTPS.

## Admin flow

`/admin` → log in → dashboard lists every post (draft + published) → write posts in
Markdown with live preview → save as draft or publish → **Settings** customizes site
title, tagline, accent color, and footer.

## Customize

- **Frontend** — everything under `client/src/` (pages, styles, layout). The accent color
  and titles come from Settings at runtime; global styles in `client/src/styles.css`.
- **Backend** — Express routes in `server/routes.ts`; content is stored in `data/blog.json`
  via `server/store.ts` — swap that one module for a database when you outgrow files.

## Deploy

```bash
pnpm build && pnpm start   # serves client + API on :4000
```

Or use the Dockerfile (`deploy-docker.yml` workflow is pre-wired) — mount a volume at
`/app/data` to persist content.

The Docker image workflow runs only when manually dispatched. This is a single-admin
prototype: it has no login throttling and stores content in a local JSON file. Restrict
network access to `/admin` and review the code before exposing an instance publicly.
